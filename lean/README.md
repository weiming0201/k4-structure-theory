# Lean 4 形式化伴随

本目录是《K4 的静态闭包与动态规范形》的直接、有限形式化伴随。它验证正文中的一组
定义、计数、反例与条件命题，不声称完成全文形式化，也不为正文增加新理论。

## 构建

```bash
lake build
```

环境固定为 Lean `v4.34.0-rc2` 与同版 mathlib；依赖修订由
`lake-manifest.json` 固定。根模块 `Lens64.lean` 只导入以下三个直接模块：

- `Lens64.K4Article`
- `Lens64.K4Article2`
- `Lens64.Cycles`

声明清单的机械口径是三个模块中行首为 `theorem` 或 `lemma` 的顶层声明。当前按该口径
共有 64 条。这个数字只描述文件清单，不代表全文覆盖率。

## 已形式化范围

| 正文位置 | 形式化强度 |
| --- | --- |
| §1.1 静态基 | 共同值域 `V` 的特化，以及正反例；未覆盖异质值域的一般形式 |
| 命题 1 | 静态基各谓词在标签置换下的不变性；未覆盖动态基一半 |
| 命题 2 | 四元素集合之间不存在由裸结构决定的典范配对 |
| §2.1 | `B_n` 的一般计数、秩计数与 `n=1…4` 表 |
| §2.2 | `W_n(k)` 的一般计数、`W_n` 定义与 `n=1…4` 表 |
| §2.3 | 只形式化 `R_4` 的秩非空投影；不是正文完整条件 |
| 命题 4 | 重复方向历史没有统一有限长度上界 |
| 命题 5 | 给定配对的函数性、一个歧义反例，以及最近匹配的具体例；未证明一般匹配算法正确性 |
| 命题 6 | 不可比元素可进入相反的线性扩展，并给出有限例 |
| 命题 7 | `B_n` 与 `B_4` 在 `n ≠ 4` 时不存在底层有限集双射 |
| §4.2 | 遗忘商的有限计数与按基数等价不保持交的反例 |
| §4.3 | 布尔闭包的乘积分解及运算保持、一个分块例、动态词非局部乘积的有限检查 |

动态乘积部分同时直接检查正文当前公式
`W_(m+n) ≠ (W_m^ε × W_n^ε) \ {(ε,ε)}` 的三个有限实例；这仍不是任意
正整数 `m,n` 的一般证明。

## 明确未纳入

- 动态基在独立标签置换下的一般不变性；
- 任意 `n=4q+r` 的迭代分块等价；
- 一般圈弹出或最近匹配算法的正确性与完备性；
- `FourSingular.lean` 的补集接缝奇异性；
- `Solvable4.lean` 的 `S₄` 可解、`S₅` 不可解及分块群作用结果；
- Krohn–Rhodes、holonomy 与 imprimitivity 的工程化分解论。

后三组材料需要先显式增加群或半群作用等新结构，因此保留为 Article 1B 候选，不能由
当前裸 K4 结构直接推出。

## 来源与发布边界

三个直接模块来自
`RESOURCES/inbox/weiming-lean-k4-article-2788827/`。收到的源码模块在显式指定时均可
编译，但原包缺少 `Lens64.lean` 根模块，因而裸 `lake build` 失败。本目录保留其证明内容，
修正发布入口与过时定位注释，并对新增的正文公式加入有限检查。

形式化成功只证明当前文件、当前环境与当前声明的编译和公理依赖；未形式化内容仍保持
未证明，不因相邻命题通过而获得效力。
