## 2. 状态词

| 状态 | 本文中的含义 |

| 已证 | 在已声明前件内已有数学推导；不越过前件推广 |
| 条件性已证 | 结论成立，但关键独立性、容量或模型假设仍是前件 |
| 模型公理 | 当前模型主动规定的次序或边界，不冒充导出的定理 |

## 3. 已经可以依赖什么

以下内容不应在每次接续时重新猜测：

1. 给定独立均匀窗口，指定长度 `m` 的二元模式概率为 `2⁻ᵐ`；
2. 给定每轮独立重采样，可接受集合 `V` 的首次命中期望为 `2ᵐ/|V|`；
3. 给定独立翻转且任一位错即失效，无保护模式的一步存活率为 `(1-p)ᵐ`；
4. 给定奇数重复码和多数解码，单步失败概率是对应二项尾和；
5. 给定四项完整独立义务、剖面保真和每个位点一比特容量，保真编码至少需要四个位点；
6. 当前模型明确区分实验者读出、个体感知和感知后的内部投影；
7. 当前模型规定闭合先于属于该个体的感知；这是模型公理，不是生命定理；
8. 当前模型把完整有界行动写成四个异型算子的有序复合，但未证明这是唯一最小分解；
9. 发布的实验设计要求相同初态、相同扰动种子、相同预算的配对对照，并允许所有核心
   假说失败；
10. 当前 Agent Frame v2 的 Observe Surface 是带来源的全系统投影；它与“个体感知外界”
    尚未完成语义对齐。

## 5. 数学问题

### M1：四项闭合义务的最小性

**问题。** 四项闭合只是当前模型的一组可消融候选，还是自我维持个体在某个清楚公理集下
不可少的四类独立义务？

**已有证据。** 条件性计数下限只证明：当四项二值义务的十六种剖面都可实现、编码必须
保真且单个位点只有一比特容量时，少于四个位点不够。它不证明现实义务独立，也不证明
高容量载体需要四个物理文件或器官。

**会改变状态的证据。**

- 构造只需三项且仍满足同一闭合判据的系统；
- 构造不能约化到四项的第五种义务；
- 给“独立义务”和“等价闭合表示”建立形式化定义，再证明受限最小性；
- 证明当前四项中某一项总能由另外三项导出。

**已有材料。** 数学基础第 2.2–2.3 节、M5–M6；既有 K4 数学结构文章和 Lean 伴随文件；
Agent Frame v2 的 Structure、Runtime、Assets、History 只作领域反例来源，不作数学前件。

**应查领域。** 信息论的充分统计量与编码下限；布尔函数独立性；代数规范与不可约签名；
自动机最小化；自创生的组织闭合；模块化系统的独立职责判据。

### M2：四算子行动的不可约性

**问题。** `D₄ ∘ D₃ ∘ D₂ ∘ D₁` 是方便的工程分解，还是在某种观测等价下的最小行动
结构？

**已有证据。** 当前只给出了四个不同输入输出类型和有序复合；删除任一步可能分别失去
可判定目标、有限策略、实际效果或可恢复结算，但这只是消融假说。

**会改变状态的证据。**

- 定义两个行动结构何时等价；
- 给出将四步压成三步且不丢失任何可观察义务的构造；
- 在冻结的类型和责任下证明任何实现至少需要四个不可互换的态射；
- 找到当前四步之外无法归因的新必要效果。

**已有材料。** 数学基础第 5 节和 M9；实验桥接第 2.4、4、10 节；Agent Frame v2 的四个
triadic faces。

**应查领域。** 程序语义、状态机最小化、进程代数、范畴中的因子分解、事务完成语义、
控制循环和部分可观察决策过程。

### M3：四宽递归的效率边界

**问题。** 把复杂动态问题递归分解为局部宽度不超过四，是否在任何有意义的条件下优于
直接使用更宽的分支？

**已有证据。** 既有组合文章解释了四元展开的有限计数和四到五的若干结构差异；当前
闭合文档没有给出任务分布、搜索成本或信息预算，因此不能推出效率结论。

**会改变状态的证据。** 必须先冻结任务族、分支成本、深度成本、并发模型、错误率、信息
获取成本和比较算法，再给出上下界或反例。若没有这些前件，“四更优”不可证伪。

**已有材料。** 数学基础 M10；公开的 K4 mathematical structure Candidate、Split Map 和
Lean 伴随文件。

**应查领域。** 决策树复杂度、在线算法、分支限界、信息获取价值、并行搜索、MDP/POMDP、
组织跨度与递归分解。工程体验只能帮助选择成本模型，不能证明结论。

### M4：编辑环境中的身份连续性

**问题。** 环境允许插入和删除后，位置、边界和“同一个体”怎样跨时间对应？

**已有证据。** 当前用外部冻结的 `≈` 表示身份接续，首轮模拟故意固定长度，只处理翻转。

**会改变状态的证据。** 一个预先声明、可计算、在编辑下稳定的身份关系；能够分别判断
移动、修复、分裂、复制与死亡；对称变换下不依赖研究者事后移动括号。

**应查领域。** 编辑距离、字符串重写系统、图匹配、持久结构、谱系追踪、双模拟与行为
等价。

### M5：冗余、成本与延续

**问题。** 哪类冗余在给定扰动和资源预算下真正提高整体闭合寿命，而不是只改善局部位？

**已有证据。** 重复码能在独立小翻转下提高单个逻辑位的可靠性；该结论没有计入存储、
感知、修复和运行成本，也没有证明整个系统寿命增加。

**会改变状态的证据。** 在相同逻辑载荷和总预算下比较复制、校验、纠删码、机制多样性、
检查点和隔离故障域，并同时报告寿命、鲁棒半径、修复收益与成本。

**应查领域。** 编码理论、容错计算、可靠性工程、冗余控制、错误恢复和资源受限优化。

## 6. 实验问题

### E1：最小模拟器与数学对拍

当前没有模拟器。第一个可复核结果只能声称实现与公式一致，不能声称出现了个体或生命。
最小证据包括：固定长度二元环、可重放翻转核、种子、模式概率、无保护寿命、重复码概率，
以及解析值与枚举/蒙特卡洛结果的误差报告。

本节点对应实验桥接的 Checkpoint 0。若实验阶段 A0 失败，应先修数学—实现接口，不能继续用实验阶段 A1–A5
的复杂行为解释失败。

### E2：感知的信息与成本

先验证 `individual_observation` 是否真的随外部条件变化，再验证该信息是否进入内部状态。
必须与 `simulator_readout` 分离，并对比无感知、打乱感知、感知但固定策略三组。需要同时
记录信息增益、预算消耗和测量扰动，允许感知净收益为负。

### E3：行动的因果收益

使用相同初态、随机种子和预算比较实验阶段 A2、A3、A4。只有完整行动相对禁用行动或固定修复在
寿命、修复率或资源效率上产生可重复改善，才能把改善归因到感知驱动的自我维持。一次成功
轨迹不够。

**应查领域。** 配对随机实验、因果推断、序贯检验、生存分析、随机过程、鲁棒控制、
viability theory 和系统辨识。

### E4：自然出现与开放演化

实验阶段 A5 只有在实验阶段 A0–A4 能区分实现错误、解释器偏置、闭合、感知和行动后才可解释。从随机世界
出发时必须冻结解释器、闭合检查、资源竞争和身份规则，记录首次闭合首达时间与谱系，不得
在看到有趣图样后移动边界。

**已有材料与外部谱系。** Barricelli 的数值演化实验、Varela–Maturana–Uribe 的自创生
模型、Ashby 的适应与超稳定系统。

**应查领域。** Artificial Life、数字演化、元胞自动机、随机重写系统、首达时间、演化
动力学、开放式演化和解释器偏置。

## 7. Agent 特化问题

### A1：Sense、Observe 与 Project

当前冲突必须先作为语义问题保留：

- Agent Frame v2：Observe 更新带来源的全系统 Account/Projection；
- 当前实验：Observe 指闭合个体通过有限接口感知边界外环境；
- 模拟器还有第三种观察：实验者对整个世界的只读观测。

可能的解释包括 `Sense → Account/Project`、Sense 与 Project 分立、或实验文档改用 Sense 而
保留 Frame 的 Observe。三者目前都不是决定。改变 Frame 前至少需要：分别写出输入、输出、
权限、状态效果和失败反例，并用同一运行案例检验是否出现职责重叠或缺口。

### A2：四项闭合的 Agent 映射

当前候选映射是 Structure、Runtime、Assets、History。它在工程上可读，但尚未证明完备或
不可约。需要找三类反例：少一项仍能稳定接续的 Agent；四项都有却无法持续行动的 Agent；
出现第五种无法归因失效的 Agent。

### A3：模型核心是否在代偿缺失结构

B0–B5 应使用同一组小型 Git 任务、Tool、权限和扰动，逐层加入 harness、Workspace、闭合
载体、环境感知和完整行动。至少测量：

- `core_rederivation`：本可机械恢复却重新交给模型推理的次数；
- `hidden_state_dependency`：清空 session 后丢失的必要状态；
- `boundary_error`：越过对象或权限边界的次数；
- `unverified_success`：无结果证据却声称完成的次数；
- `recovery_distance`：故障后恢复合法行动所需步骤和模型调用；
- `substitution_loss`：更换模型或 harness 后丢失的身份、历史和能力。

**应查领域。** 软件可靠性、Agent benchmark 设计、故障注入、可恢复工作流、可观测性、
人机协作、能力安全边界和差分测试。只有受控运行结果可以支持修改 Agent Frame。

## 8. 独立研究线

以下题目不应混入最小工程实验：

1. 量子测量是不是随机性的必要或唯一来源；
2. 一个可插入、删除和坍缩的无限二元序列能否完备表示物理世界；
3. 外部观察是否必然改变被观察系统；
4. 从无语义随机串到闭合谓词的自然选择是否几乎必然；
5. 闭合、自创生、生命和意识是否可以等价。

若以后进入这些问题，应建立新的 Observe 边界，分别装载量子信息、随机过程、物理测量、
生命哲学或意识理论的第一方材料。不能用当前工程模拟的有趣结果替代物理或哲学证明。
