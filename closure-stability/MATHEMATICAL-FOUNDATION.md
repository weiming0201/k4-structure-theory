# 随机扰动下闭合个体的数学基础（初稿）

> 状态：隔离 Candidate；不是已采用理论，也不是生命定义。
>
> 本文只建立实验可以依赖的数学对象、条件性结论和反例边界。现实工程映射、历史类比与
> 实验实现均不在本文中。

## 0. 研究问题与结论边界

本文研究一个有限问题：在一个持续受到随机扰动的离散环境中，什么条件足以区分以下五件事：

1. 某个局部模式偶然出现；
2. 一个有边界的局部系统在某时刻闭合；
3. 闭合系统感知其外部环境；
4. 系统依据感知完成一次有界行动；
5. 行动提高其在给定身份尺度上的延续能力。

这五件事不能互相替代。出现不等于闭合，闭合不等于感知，感知不等于行动，行动也不等于
提高延续概率。

本文当前能严格支持的是：

- 二元窗口和有限模式的基本计数；
- 给定独立性与位点容量后，四坐标下限；
- 给定扰动模型后，无保护模式和重复码的失效概率；
- 给定可生存集合后，存活时间、鲁棒半径和受限最优策略的定义；
- 给定四个阶段算子后，一次完整行动是其有序复合。

本文不能推出：

- 随机序列必然产生闭合个体；
- 闭合所需的四项义务天然独立；
- 物理随机性的来源必须是量子测量；
- 四分在任意成本函数下都最优；
- 满足本文形式条件的对象就是生物生命。

## 1. 随机环境

### 1.1 状态空间

令二元字母表为：

```text
Σ = {0,1}.
```

一般环境状态取自有限二元串的并：

```text
Ω = ⋃ₙ≥0 Σⁿ.
```

时间离散，环境按转移核演化：

```text
Xₜ₊₁ ~ K_env(· | Xₜ).
```

`K_env` 可以包含替换、插入和删除。本文不规定这些随机数来自热噪声、量子测量、伪随机
生成器还是外部输入；只要求给定实验中的核和随机种子可复现。随机源的物理本体是另一个
问题，不是以下数学结论的前件。

首轮可计算模型使用固定长度环：

```text
Ω_N = Σᴺ,
```

每个位置在一步内以概率 `p` 独立翻转。变长编辑核留给后续实验，因为插入和删除还需要
定义位置身份怎样跨时间对应。

### 1.2 外部读出与系统感知

实验者读取 `Xₜ` 是元层操作，记为：

```text
Rₜ = Readout(Xₜ).
```

它不自动成为环境内某个局部系统的感知。局部系统的感知必须通过该系统自己的状态和接口
发生，见第 4 节。两种观察在全部定义和数据中必须分开命名。

## 2. 局部系统、边界与身份

### 2.1 候选局部系统

在时刻 `t`，一个候选局部系统写成：

```text
Eₜ = (Iₜ, zₜ, eₜ).
```

- `Iₜ` 是 `Xₜ` 中被声明为内部的有限位置集合；
- `zₜ` 是从 `Iₜ` 解码出的内部状态；
- `eₜ` 是其余位置对 `Iₜ` 的有效外部条件。

仅仅选定 `Iₜ` 相当于外部研究者画了一个括号，不能证明括号由系统自身维持。一个有效边界
还必须给出可检验投影 `B(Eₜ)`，说明内部与外部的交换受到系统状态约束，而且边界在允许
扰动下可以被保持或重建。`B` 是后述联合闭合在空间上的边界读出，不是第五项闭合义务。

### 2.2 四项闭合义务

设有四个二值谓词：

```text
qᵢ : Z → {0,1},  i ∈ {1,2,3,4}.
```

它们暂时只表示四项分别可检验的闭合义务，不预先赋予工程名称。定义：

```text
C(z) = q₁(z) ∧ q₂(z) ∧ q₃(z) ∧ q₄(z).
```

`C(z)=1` 表示在当前尺度和检查合同下四项义务同时成立。闭合是四项联合性质，不是第五个
内部位点；外部括号是闭合成立时对边界的投影，也不是第五项义务。

四项义务为什么恰好是这四项、是否相互独立，是待验证的建模假说。数学只负责说明：一旦
选择了四项独立义务和受限表示位点，会产生什么结论。

### 2.3 条件性四坐标下限

令：

```text
profile : Z → {0,1}⁴
profile(z) = (q₁(z),q₂(z),q₃(z),q₄(z)).
```

加入三个前件：

1. **完整独立性：** 十六种剖面都可实现；
2. **剖面保真：** 编码相同的状态具有相同剖面；
3. **位点容量：** 每个静态位点只能保存一个二值坐标。

**定理 1（条件性下限）。** 若 `m` 个二值位点对全部十六种剖面保真，则 `m ≥ 4`。

**证明。** 完整独立性和剖面保真给出单射：

```text
{0,1}⁴ ↪ {0,1}ᵐ.
```

因此 `16 ≤ 2ᵐ`，所以 `m ≥ 4`。证毕。

若单个位点可保存任意对象，则一个位点即可保存整个四元组，结论失效。因此“至少四个
位点”不是从四个名称得到的，而是独立性、保真和容量限制的联合结论。该结果已有本地 Lean
候选验证；本文不重复把领域独立性冒充为已证前提。

### 2.4 身份连续性

闭合只描述一个时刻。跨时刻的同一个体需要等价或接续关系：

```text
Eₜ ≈ Eₜ₊₁.
```

关系 `≈` 必须由实验预先定义，例如允许边界平移、有限组件替换、可恢复编码变化，但不允许
任意两个闭合状态因“功能相似”就被事后认作同一个体。

个体的死亡时刻定义为：

```text
τ = inf { t ≥ 0 : C(zₜ)=0 或 Eₜ₋₁ ≉ Eₜ }.
```

这里的死亡只是数学上的闭合或身份连续性终止，不是生物学或伦理判断。

## 3. 偶然出现与自然寿命

### 3.1 有限模式出现概率

设长度为 `m` 的窗口在某次独立均匀重采样中取值。指定模式 `w∈Σᵐ` 出现的概率为：

```text
P(W=w) = 2⁻ᵐ.
```

若可接受模式集合为 `V⊆Σᵐ`，则：

```text
P(W∈V) = |V| / 2ᵐ.
```

若每轮窗口独立重采样，首次命中 `V` 的等待轮数 `T` 服从几何分布：

```text
E[T] = 2ᵐ / |V|.
```

局部翻转、重叠窗口和插入删除会产生时间相关性，此时不能直接套用几何等待时间，必须研究
对应马尔可夫链的首达时间。

### 3.2 无保护模式的寿命

假设一个长度为 `m` 的模式只要任一位翻转就失效，每位每步以概率 `p` 独立翻转。一步保持
有效的概率为：

```text
s₀ = (1-p)ᵐ.
```

令 `L` 是从当前有效状态开始、直到第一次失效所经历的步数，且 `L∈{1,2,…}`，则：

```text
P(L=k) = s₀ᵏ⁻¹(1-s₀),
E[L] = 1 / (1-s₀).
```

这给出无维护对照组。它只衡量模式的被动稳定，不衡量闭合、自我修复或感知。

### 3.3 重复码的局部保护

把一个逻辑位复制为奇数 `r` 个物理位，以多数表决解码。单步解码失败概率为：

```text
P_fail(r,p) = Σₖ₌₍ᵣ₊₁₎⁄₂ʳ C(r,k)pᵏ(1-p)ʳ⁻ᵏ.
```

当 `p→0` 时，主导阶为：

```text
P_fail(r,p) = Θ(p^((r+1)/2)).
```

因此重复码能提高小扰动下的局部可靠性，但存储成本扩大为 `r` 倍。它证明“冗余可以换取
可靠性”，不证明某种冗余在总成本上最优，也不等于整个系统闭合。

## 4. 闭合之后的感知

### 4.1 感知通道

只有在 `C(zₜ)=1` 时，个体才被允许调用其内部感知核：

```text
Yₜ ~ Q(· | zₜ, eₜ).
```

这是模型的次序公理：**先有能够维持自身边界和内部职责的个体，才有属于该个体的感知。**
若 `C(zₜ)=0`，外部仍可读取残余模式，但不把该读出称为此个体的感知。

感知成立至少需要：

```text
I(Yₜ ; eₜ | zₜ) > 0,
```

或在有限实验中用等价的可区分性检验：存在两种外部条件，使 `Yₜ` 的条件分布不同。只有
内部变量随外部条件发生可重复区分，才称为感知；数据恰好相关一次不够。

### 4.2 测量扰动

感知可以有代价。用感知核后的环境转移记为：

```text
K_obs(· | Xₜ,zₜ),
```

不用感知时仍为 `K_env`。两者的差可以表示读取耗能、接口占用、暴露或测量反作用。该差
无需具有量子来源；量子测量只是未来可能代入的一种物理实现。

## 5. 一次有界行动

### 5.1 四个算子

令 `Ξ` 表示有效外部条件空间。闭合个体从感知结果出发，依次应用四个不同类型的算子：

```text
D₁ : Z × Y → G
D₂ : Z × Y × G → P
D₃ : Z × Ξ × P → Z × Ξ × O
D₄ : Z × O → Z × H.
```

- `D₁` 选择本轮欲保持或改变的可判定状态；
- `D₂` 形成受资源与失败分支约束的策略；
- `D₃` 实际改变内部或环境并产生可观察输出；
- `D₄` 结算结果、更新接续信息并结束本轮行动权。

这些是抽象类型，不预设工程名称。一次**完成的行动**定义为有序复合：

```text
A = D₄ ∘ D₃ ∘ D₂ ∘ D₁.
```

只有 `D₄` 完成并给出下一可恢复状态时，本轮才算完成。中途输出可以是真实事件，但不能
冒充完整行动结果。

此处没有证明四算子是所有行动的唯一最小分解。它只给出一个可消融的候选：删除任一算子
后，实验检查是否仍能同时保持可判定目标、有限策略、实际效果和可恢复结算。

### 5.2 受限相对最优

给定可行动作集 `A(z,y)`、预算 `b` 和可生存集合 `V={z:C(z)=1}`，策略 `π` 的目标可以写为：

```text
π* ∈ argmax_π P_π(τ > T | z₀∈V, budget≤b),
```

或最大化期望寿命：

```text
π* ∈ argmax_π E_π[τ | budget≤b].
```

“相对最优”只相对于给定状态表示、动作集、扰动核、身份尺度、预算和时间窗。它不是宇宙
范围内的绝对最优，也不推出增长、繁殖、复杂化或资源占有本身是目标。

## 6. 自我维持与鲁棒性

### 6.1 反事实自我维持

一个闭合快照可能只是偶然稳定。要检验主动自我维持，使用相同初态和相同随机种子的配对
反事实：

```text
P(C(zₜ₊₁)=1 | action enabled)
>
P(C(zₜ₊₁)=1 | action disabled).
```

实际实验比较寿命分布、修复成功率和成本，而不是只比较单步结果。若启用行动没有产生可
重复改善，就不能把持续存在归因于自我维持。

### 6.2 鲁棒半径

设扰动集合为 `Δ`，成本为 `cost(δ)`。闭合状态 `z` 的鲁棒半径定义为：

```text
ρ(z) = inf { cost(δ) : C(δ(z))=0 }.
```

`ρ` 衡量使闭合立即失效所需的最小扰动。寿命 `τ` 衡量连续时间上的持久性。两者不同：
一个系统可以抵抗较大单次扰动，却因小扰动累积而寿命短；也可以单步脆弱但依靠快速修复
获得较长寿命。

### 6.3 冗余不等于重复权威

数学上可以有多种物理编码共同重建一个逻辑状态。若解码函数为：

```text
decode : Carrier → LogicalState,
```

则多个载体可以提供纠错冗余，而逻辑状态仍保持唯一。可靠性来自可验证重建关系，不来自
多个互相冲突的逻辑真值。

可比较的冗余族至少包括：

- 直接复制；
- 多数表决；
- 校验和与纠删码；
- 不同机制实现同一逻辑功能；
- 周期检查点与恢复；
- 隔离故障域后的交叉核对。

## 7. 谱系与更高层闭合

若一个个体产生新的闭合系统 `E'`，且 `E'` 具有独立边界和独立身份连续关系，则它是新的
个体，不是原个体简单变长。谱系关系可以写为：

```text
Parent(E,E').
```

个体寿命与谱系寿命必须分开统计。复制、繁殖、分裂和合作可能提高谱系延续，但不等于延长
原个体身份。

多个个体只有在它们的组合自身再次满足边界、四项闭合、感知和身份连续时，才构成更高层
闭合系统。仅仅通信、依赖或共同出现不足以建立上层个体。

## 9. 实验必须遵守的数学合同

任何实现若声称测试本文，至少必须显式给出：

1. 状态空间与随机转移核；
2. 内外边界及其跨时间对应；
3. 四个闭合谓词和身份接续关系；
4. 个体感知核与实验者读出的区别；
5. 动作集合、资源预算与四算子完成条件；
6. 可生存集合、寿命、鲁棒半径和成本；
7. 相同初态、相同扰动种子的禁用行动对照；
8. 每项猜想对应的可失败判据。

缺少其中任何一项，仍可得到模拟结果，但不能把结果归因到本文对应主张。

## 10. 留给独立题目的问题

以下问题有研究价值，但本稿不使用其答案：

- 宇宙是否能被一个随机编辑的二元序列完备表示；
- 测量是否是随机性的必要或唯一来源；
- 外部读取是否必然改变被读系统；
- 从无语义随机串到闭合谓词的自然选择是否几乎必然；
- 闭合、自创生、意识和生命是否可以等价。

它们需要独立的物理、概率或认识论模型。把它们留空不会削弱本稿对工程稳定策略的实验。
